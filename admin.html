Library

Upload a file once and receive a public share link. Supports HTML, PDF, images, text, office documents, and ZIP. HTML is served in a sandboxed, isolated context that cannot read CommonUnity cookies or sessions.

Upload a file

HTML, PDF, PNG/JPG/WebP/GIF/SVG, TXT/MD, DOCX/PPTX/XLSX, ZIP.

How share links work

Each upload gets a stable URL at /share/<slug> on commonunity.io. PDFs, images and text render inline; office files and ZIP download. Uploaded HTML runs in a unique sandboxed origin — it can present freely but cannot access admin or beta cookies, storage, or credentialed APIs. Deactivating hides a link without deleting bytes; deleting removes the bytes and kills the URL permanently.
